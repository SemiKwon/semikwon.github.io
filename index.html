로컬 LLM 기반 문서 검색 및 신뢰도 평가

  • 표현 차이 및 이미지형 PDF로 인한 정보 탐색의 어려움

  • 선택적 OCR → 청크 분할 및 문서/청크 구조화

SQL 쿼리 보기 
SELECT
    d.filename,
    d.category,
    MIN(c.id)   AS first_chunk_id,
    COUNT(c.id) AS chunk_count
FROM documents d
LEFT JOIN chunks c
  ON c.document_id = d.id
GROUP BY d.id, d.filename, d.category
ORDER BY d.filename;
